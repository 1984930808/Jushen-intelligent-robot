# 算法原理

## 1. 任务定义

本项目解决工业场景下的多类别目标检测问题：在 RGB 图像中定位并识别 17 类工业组件（按钮、背板、电池盒、屏幕、PCB、金属托盘等），输出边界框与类别置信度。

## 2. 模型结构（YOLOv11）

采用 Ultralytics YOLOv11n 单阶段检测器，整体流程：

1. **Backbone**：提取多尺度特征  
2. **Neck**：融合高低层语义与细节信息  
3. **Head**：并行预测目标类别、置信度与边界框  

相比两阶段检测器，YOLO 在工业产线实时性与精度之间更易取得平衡。

## 3. 训练流程

```text
原始标注(XML/JSON)
    -> convert_to_yolo.py（转 YOLO txt）
    -> split_dataset.py（train/val/test）
    -> train.py（YOLOv11 训练）
    -> best.pt（推理权重）
```

关键训练设定：

- 输入尺寸：640×640  
- 优化器：AdamW / auto  
- 数据增强：Mosaic、颜色抖动、随机翻转、随机擦除等  
- 损失：边框回归 + 分类 + DFL  

## 4. 推理流程

```text
输入(图片/视频/摄像头)
    -> 预处理(缩放/归一化)
    -> YOLOv11 前向
    -> NMS(conf/iou 阈值)
    -> 可视化与结果保存
```

入口脚本：

- `run_demo.py`：仓库自带样例快速验证  
- `predict.py`：完整推理（图片/视频/摄像头/批量）  
- `predict_simple.py`：最小示例  

## 5. 应用场景

- 工业装配线视觉质检  
- 仓储/托盘上的部件盘点  
- 产线工位监控与统计  
- 为下游机器人抓取提供视觉定位输入（**本仓库仅开源视觉检测部分；机械臂运动规划不在本包范围内**）  

## 6. 与机械臂系统的边界

若产线需要“检测 → 位姿估计 → 机械臂规划”全链路：

- **本开源包负责**：目标检测（框 + 类别）  
- **不包含**：运动学规划、轨迹优化、抓取成功率评估  

因此 README 性能指标只报告视觉识别指标（mAP / Precision / Recall），不报告机械臂规划成功率。
